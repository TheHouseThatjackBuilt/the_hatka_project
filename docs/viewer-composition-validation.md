# R2.2: композиция просмотрщика

Завершено 2026-09-15. Пользователь разрешил R2.2 и подтвердил тёмную тему,
измерения справа на desktop и снизу на мобильном.

## Изменения и границы

- Canvas заполняет экран под интерфейсом. Header 48 px, вид и настройки слева,
  камера справа снизу, статус и раскрываемая справка. На узком экране группы
  становятся горизонтальными; короткое горизонтальное окно использует боковую
  раскладку. Минимальная высота приложения — 320 px.
- Основной экран использует локальный IBM Plex Sans и примитивы R1:
  SegmentedControl, Toggle, Button, IconButton, Tooltip, FloatingPanel, StatusBadge.
  Скачивание остаётся ссылкой с download, оформленной как secondary.
- Вращение, zoom, панорамирование, статический срез 1,05 м, загрузка и ошибка
  сохранены. Отдельный сброс камеры остаётся R3.2.
- Невидимая ячейка CSS grid задаёт свободный прямоугольник для fit. Хук передаёт
  getter через createViewer в контроллер камеры. Fit читает актуальную область,
  заполняет 88% ограничивающей оси и сохраняет ракурс. Пустая или невалидная
  область заменяется всем canvas, частично выходящая за него — ограничивается.
- Открытие/закрытие измерений не вызывает fit и сохраняет zoom/pan. Кнопка
  «Вписать модель», смена вида и resize окна учитывают размещение панели.
- Для работоспособности новой композиции панель измерений уже размещена в сетке
  и получила цвета темы. Это необходимая интеграция R2.2: её native кнопки/select,
  вычисления, выбор и SVG не заменялись. Полное оформление измерений — R2.3.
- Геометрия, генератор, экспорты, зависимости и конфиги сборки не менялись.

## Автоматические проверки

Node 24.14.0: typecheck, 60 тестов, build с model:check (619 деталей),
format:check и git diff --check проходят. Новые тесты проверяют смещённую область,
центрирование, fill, сохранение ракурса, повторный fit, изменение области без fit,
невалидные и выходящие за canvas прямоугольники.

Vite предупреждает о viewer chunk 629,53 kB / 170,24 kB gzip. Это прежнее
ограничение размера chunk, сборку оно не прерывает.

квартиры может оказаться за панелью до ручного fit. Это выбранное поведение.
Физические touch-жесты, screen reader и полный повтор математики/выбора всех
измерений в браузере не проверялись. Подписи top на узком экране ещё могут
пересекаться: их переработка относится к R3.1. Следующий шаг — R2.3.
