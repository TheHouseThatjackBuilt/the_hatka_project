# R1.1: визуальная основа

Проверено 2026-09-14, Windows, Node 24.14.0, встроенный Chromium.
Основание — разрешение пользователя приступить после R0.2.
Выполнен R1.1 из [плана](viewer-redesign-plan.md).

## Реализация

- `src/design-system/tokens.css`: 22 базовых токена брифа и 14 семантических
  дополнений для шрифта, контролов и фокуса. Область — `.hatka-theme`.
- IBM Plex Sans Regular 400 / Medium 500, локальные оригинальные WOFF2
  суммарно 129 760 байт, `font-display: swap`, SIL OFL 1.1.
  [Источник и SHA-256](../src/design-system/fonts/README.md).
  Лицензия включена в production assets и доступна из demo.
- `?ui=foundations`: изолированный экран образцов вместо App, загружаемый
  через React.lazy. Палитра, кириллица/латиница 11/12/13/15 px, 400/500,
  цифры, нативные контролы для проверки фокуса, отступы и скругления.
  Это ещё не библиотека компонентов R1.2/R1.3.
- Старые `App.tsx`, `styles.css`, viewer, модель и экспорты не изменены.
  Демо использует отдельный CSS chunk; обычная квартира не загружает
  новые шрифты и стили. Возврат по «К квартире» — полная навигация.

## Проверки

`npm run typecheck`, `npm run test` (47/47), `npm run build`
(включая model:check, 619 деталей) и `npm run format:check` прошли.
Повторная сборка после добавления ссылки на лицензию успешна.
Новых зависимостей нет. Сохраняется прежнее предупреждение Vite:
viewer 628,23 kB / 169,81 kB gzip превышает порог 500 kB.

Браузерная проверка dev на 1440×900 и 390×844:

- Демо читается, на узком экране одна колонка; горизонтального скролла нет.
  Сняты [desktop](assets/foundations-2026-09-14/desktop.png) и
  [mobile](assets/foundations-2026-09-14/mobile.png).
- Оба начертания имеют статус `loaded`; запросы WOFF2 идут на localhost.
  Кириллица, в том числе ё/ъ/ь, отображается в образцах.
  [Результат загрузки](assets/foundations-2026-09-14/font-loading.txt).
- «Сменить цифры» меняет `11,11 × 11,11 м` на `88,88 × 88,88 м`;
  ширина output в обоих случаях 110,984375 px, computed style — tabular-nums.
- Tab с кнопки переходит в поле комнаты: focus-visible, outline 2 px
  цвета accent, offset 3 px. Далее select и ссылка лицензии; disabled
  пропускается. У disabled отдельный цвет и cursor not-allowed.
- В demo нет canvas. В обычном просмотрщике один canvas, прежний системный
  шрифт и только старый stylesheet. Новых font faces и запросов шрифтов нет:
  [результат](assets/foundations-2026-09-14/viewer-loading.txt).
- У квартиры проверены cut/full/top, выключение/включение мебели и названий,
  кнопки zoom, поворота, панорамирования и fit, открытие измерений и resize
  до 390×844. Снимки: [cut](assets/foundations-2026-09-14/viewer-cut.png),
  [full](assets/foundations-2026-09-14/viewer-full.png),
  [top](assets/foundations-2026-09-14/viewer-top.png),
  [измерения на узком экране](assets/foundations-2026-09-14/viewer-mobile-measurements.png).
- В проверенных вкладках dev и production нет ошибок и предупреждений консоли.
  Через `npm run preview -- --port 5174` открыто
  [production demo](assets/foundations-2026-09-14/production.png), проверены
  отдельный stylesheet, путь лицензии и возврат к квартире: новый stylesheet
  исчезает, canvas создаётся один.

Загрузку font faces и ресурсов измерял временный диагностический HTML в `.tmp/`,
импортирующий обычный main. Он не входит в сборку и удалён после проверки.

## Границы проверки

В системе reduced-motion выключен; computed transition — 0,12 s. Правило
`prefers-reduced-motion: reduce` меняет общий токен на `0ms linear`; проверено
по коду. Переключение системной настройки и поведение при ней браузером
не проверялись: у доступного инструмента нет эмуляции этого media feature.

Отдельный анализ покрытия всех глифов не выполнен: fontTools отсутствует.
Проверены фактическая загрузка начертаний и видимые образцы кириллицы.
Жесты физических touch-устройств, полный повтор приёмки измерений и новый
замер FPS не выполнялись: их код не менялся. Известные проблемы мобильной
панели и пересечения подписей из R0.2 остаются задачами следующих этапов.

Следующий шаг — R1.2: Button, IconButton, FloatingPanel, StatusBadge и Toggle.
