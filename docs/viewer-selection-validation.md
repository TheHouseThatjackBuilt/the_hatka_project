# R1.3: выбор и подсказки

Проверено 2026-09-14 после разрешения пользователя приступить. Выполнен R1.3
из [плана](viewer-redesign-plan.md); все восемь примитивов R1 доступны на
`?ui=foundations`. Основной просмотрщик пока сохраняет прежнее оформление.

## Реализация

- `SegmentedControl.tsx`: native radio group, обязательное имя группы,
  horizontal/vertical, sm/md, отключение группы или отдельной опции.
- `Select.tsx`: собственный select-only combobox с listbox, без native select
  внутри компонента. DOM-фокус остаётся на trigger; active descendant
  прокручивается в пределах списка. Enter/Space и Tab подтверждают выбор;
  Escape, повторный click trigger и внешний click отменяют просмотр вариантов.
  Стрелки, Home/End и Page Up/Down пропускают disabled. Есть поиск по префиксу
  и циклический поиск повтором буквы; пустой список отключён.
- `Tooltip.tsx`: render prop для передачи aria-describedby, появление через
  токен 400 ms по focus/hover, role tooltip, Escape в том числе до появления,
  очистка таймеров. Курсор можно перевести на подсказку; мост 80 ms удерживает
  её при пересечении зазора. Анимации ухода нет; blur без hover закрывает сразу.
- Всплывающие элементы создаются через portal с собственной `.hatka-theme`.
  Select перепозиционируется при scroll/resize, Tooltip закрывается.
  Положение ограничено окном, список может открываться вверх.
  Добавлены только два семантических токена слоёв: popup и tooltip.
- `SelectionPreview.tsx`: три группы режимов, список из 134 демонстрационных
  пунктов, disabled/empty, подсказка и удаление/возврат Select для проверки
  cleanup. Список не выдаётся за каталог или размеры реальной квартиры.

Семантика и клавиатура сверены с
[APG select-only combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/)
и [tooltip pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/).
Явное отличие Select: blur/внешний click отменяют просмотр, Tab подтверждает.
Скринридерная совместимость не объявляется подтверждённой одной этой сверкой.

## Проверки

Node 24.14.0: typecheck, 49 тестов (47 прежних и 2 новых), build/model:check
и format:check прошли. `git diff --check` чистый. Новые тесты проверяют
пропуск disabled, границы и прыжки по списку, кириллические префиксы,
повторы букв и отсутствие совпадения. Новых зависимостей нет.
Сохраняется предупреждение Vite о viewer chunk 628,23 kB.

Браузер: встроенный Chromium; desktop 1440×900 и mobile 390×844/DPR 1.

- ArrowRight меняет первый radio group с cut на full. ArrowDown в вертикальной
  группе пропускает disabled full и выбирает top. Disabled-группа сохраняет cut.
- ArrowDown в Select пропускает недоступный предмет. Значение trigger до
  подтверждения не меняется, DOM-фокус остаётся на combobox. Escape отменяет.
- End показывает последний пункт списка; scrollTop на desktop — 4526 px.
  Enter выбирает его. Tab подтверждает и переходит на кнопку подсказки,
  пропуская два отключённых Select.
- Click по «Стол · кухня-гостиная» выбирает пункт, закрывает listbox и сохраняет
  фокус на trigger. Удаление открытого Select из demo удаляет portal;
  после возврата компонент снова открывается.
- Сразу после focus tooltip отсутствует, через 450 ms присутствует и связан
  через aria-describedby. Escape скрывает, повторный focus вновь открывает.
  Escape во время ожидания отменяет таймер: спустя 500 ms подсказки нет.
- Hover открывает подсказку. Перевод курсора на неё сохраняет видимость;
  уход за её пределы закрывает. [Кадр](assets/selection-2026-09-14/tooltip.png).
- На mobile listbox и активная последняя строка в окне; длинное имя переносится.
  Popup 309×256 px, scrollWidth страницы 375 px при innerWidth 390 px.
  [Desktop](assets/selection-2026-09-14/select-desktop.png),
  [mobile](assets/selection-2026-09-14/select-mobile.png),
  [подсказка mobile](assets/selection-2026-09-14/tooltip-mobile.png).
- Проверена production-сборка через preview: End/Enter, Tab и Tooltip работают.
  В dev и production нет ошибок/предупреждений консоли.
- Обычный просмотрщик подключает только прежний styles.css и создаёт один
  canvas. Проверены cut/full/top, мебель/названия off/on, поворот, fit и
  открытие измерений. Сцена, геометрия и её экспорты не изменялись.

## Границы

Кириллический typeahead проверен Node-тестом; browser press не поддерживает
ввод таких клавиш в этой среде. Физические touch-жесты и скринридер не проверены.
Системный reduced-motion не переключался: переходы используют прежний токен,
который обнуляется соответствующим media query; проверено по коду.
Полная приёмка измерений и замеры FPS не повторялись, их реализация не менялась.

Следующий этап — R2.1: кадрирование и resize; затем интеграция примитивов
в композицию просмотрщика с сохранением измерений.
