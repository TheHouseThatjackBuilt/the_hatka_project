**Результат переноса генератора на TypeScript**

8 сентября 2026 года. Первый этап завершён: генератор, сериализаторы и командная строка работают на TypeScript. Старый `scripts/build_model.py` удалён; дополнительных зависимостей не добавлено.

**Что изменилось**

- Общая сборка находится в `src/modeling/build-apartment.ts`.
- Код разделён на `core`, `furniture`, `rooms`, `shell` и `export`.
- У каждого вызова сборки собственные детали, материалы и подписи. Глобального накопительного списка и построения модели при импорте нет.
- Общий код не использует React, DOM, WebGL, Node Buffer или файловую систему. GLB создаётся через типизированные массивы и DataView.
- Только `scripts/build-model.ts` обрабатывает аргументы и записывает файлы.
- `npm run model:build` создаёт четыре экспорта; `--output-dir` позволяет выбрать папку.
- `npm run model:check` проверяет актуальность файлов без записи. Эта проверка включена в `npm run build`; workflow также запускает тесты.

**Сравнение с исходной моделью**

Перед переносом исходный Python-скрипт запущен в отдельную временную папку. Все четыре его результата совпали с файлами проекта: JSON по данным, GLB/OBJ/MTL побайтно. Таким образом, не было скрытого расхождения между исходниками и опубликованными в репозитории экспортами.

JSON.stringify записывает целые значения без `.0` и нормализует `-0` в `0`. Это учтено при сравнении, не меняет геометрию и не является изменением схемы. Округление дробных значений сохраняет исходное правило nearest-even; проверены половинные значения, отрицательные числа и крайние конечные значения.

Эталон геометрии и независимые отпечатки экспортов сохранены в `tests/fixtures/`. Их тестирование не требует Python.

**Автоматические проверки**

`npm test`: 24 теста проходят. Они включают существующие проверки просмотрщика и новые проверки:

- соответствия всей модели эталону;
- повторной генерации без накопления деталей и совместно используемых изменяемых массивов;
- независимой сборки кухни и кабинета;
- округления, некорректных размеров и поворота группы новых деталей;
- соответствия сериализаторов независимым отпечаткам старого экспорта;
- чтения GLB через GLTFLoader: два независимых дерева сцены, все трансформации и правильная принадлежность потолка;
- чтения OBJ через OBJLoader: все детали без потолка, материалы и положения в мировой системе;
- запуска CLI из другой рабочей папки, пути с пробелами, ошибок аргументов, отсутствующих/устаревших файлов и отсутствия записи при `--check`.

`npm run build` проходит: актуальность экспортов, строгая проверка типов, production-сборка Vite. `npm run format:check` проходит. Проверка типов включает новый CLI и тесты.

Общий генератор и сериализаторы отдельно собраны Vite как браузерные ES-модули. Они также выполнены на временной проверочной странице во встроенном браузере: созданы модель, JSON, GLB, OBJ и MTL; модель совпала с JSON сайта. Это проверка реальной работы без Node.js API, а не только успешной компиляции.

**Проверка сайта**

Проверены разрез, план сверху и режим полных стен. Скриншот разреза до и после миграции совпал побайтно в том же браузере и размере окна. Существующий интерфейс и код просмотрщика не менялись.

**Граница этапа**

Детали пока используют прежние мировые координаты и формат model.json. Предметных id, локальных координат, React Three Fiber и перетаскивания ещё нет — это следующий этап. Браузерная проверка общего генератора не добавляет в пользовательский интерфейс новый редактор или кнопку скачивания изменённого GLB.

Изменения подготовлены в рабочей папке; публикация сайта и push не выполнялись. Старый генератор доступен в истории Git, а исторические материалы в `reference/` сохранены.
