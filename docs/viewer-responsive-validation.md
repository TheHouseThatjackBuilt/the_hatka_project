Дата: 2026-09-27. Статус: браузерный проход выполнен; согласование исключения
из лимита ширины панелей остаётся открытым. R5.1 пока не отмечен завершённым.

## Лимит 20% — требуется решение

На 1440×900 панели занимают по ширине:

- инструменты слева — 160 px;
- камера справа — 50 px;
- открытые измерения — 288 px.

Без измерений сумма 210 px / 14,6%, с измерениями — 498 px / 34,6%.
Это сумма ширин самих панелей, без полей и промежутков; свободная область
fit с измерениями имеет ширину 874 px. Бриф требует не более 20%, а R5.1
предусматривает согласование исключения для открытых измерений.
Предложено сохранить текущую ширину 288 px для читаемости данных и считать
лимит 20% применимым к основным панелям при закрытых измерениях. Ответ ожидается;
исключение не считается принятым автоматически.

## Ограничения

На 320×740 с открытыми измерениями модель мала; закрытие панели возвращает
место сцене. Более короткие портретные окна в этом проходе не проверялись.
Контролы сохраняют размеры 28/32 px из принятой визуальной системы.

Read-only аудит controls подтверждает обработку pointer capture, вращения
одним указателем, pan/pinch двумя и отмены жеста. Существующие Node-тесты
проверяют порог tap и отмену выбора при втором касании, но не заменяют реальные
touch-жесты. Доступный браузерный инструмент не предоставляет multitouch;
физические pinch/pan и удобство пальцевого ввода остаются непроверенными.

Этот проход не является полной итоговой регрессией R5.2. Новые тесты и сборка
не запускались: изменена только документация и добавлены артефакты проверки.
