# R2.1: вписывание и resize

Завершено 2026-09-15, работа начата 2026-09-14. Основание — разрешение перейти
к R2.1 и явный выбор пользователя: при открытии «Размеров» сохранять
приближение; автоматически вписывать только после изменения окна.

## Изменения

- `camera.ts`: fit использует текущую проекцию, центрирует видимую геометрию
  без сброса ракурса, сохраняет прежний целевой fill 0,88 и пределы zoom
  0,35–6. Повторный fit идемпотентен. Нулевой размер не создаёт бесконечных
  матриц; отложенный fit загрузки/смены режима выполняется после восстановления.
- `resize-fit.ts` и `index.tsx`: window resize запускает debounce 150 ms;
  ResizeObserver сразу меняет размер renderer и продлевает ожидающее вписывание.
  Изменение только canvas из-за панели измерений не запускает fit.
  Ручные zoom, rotate, fit и начало жеста отменяют ожидание. Скрытая область
  ждёт восстановления без периодического таймера; ожидание также отменяется.
  Dispose очищает таймер, observer и новые window/canvas listeners.
- Текущая свободная область равна canvas: существующая панель измерений
  расположена вне него. Спекулятивный API отступов будущих overlay не добавлен;
  он относится к интеграции композиции R2.2/R2.3.
- Генератор, геометрия, экспорты, зависимости и конфиги не менялись.

## Автоматические проверки

Node 24.14.0: прошли typecheck, 57 тестов, build с model:check (619 деталей),
format:check и git diff --check. Vite по-прежнему предупреждает о размере
viewer chunk: теперь 629,06 kB / 170,07 kB gzip.

Новые проверки камеры: сохранение quaternion после взаимодействий во всех
видах, центрирование и fill 0,88, повторный fit, portrait → landscape,
нулевые ширина/высота и восстановление, предельный zoom. Отдельные три теста
таймера проверяют debounce, отмену/cleanup и ожидание скрытой сцены без polling.

StrictMode, читает actual camera/scene и выводит результат в DOM. Исходник —
[fit-probe.js](assets/camera-fit-2026-09-14/fit-probe.js),
полные данные — [results.json](assets/camera-fit-2026-09-14/results.json).
Временный HTML в `.tmp/` удалён после проверки; probe не входит в production.

[кадр с измерением](assets/camera-fit-2026-09-14/mobile-measurements.png).
Ошибок консоли в проверенных вкладках нет.

Изменение aspect при открытии панели всё ещё меняет доступный кадр: сохраняется
выбранный zoom и положение камеры, а не гарантия видимости всей квартиры при
ручном приближении. Для полного вида остаётся кнопка «Вписать модель».
Физические touch-жесты и полный повтор всех инструментов измерений не проверялись;
их вычисления и обработчики не менялись. Новые панели и оформление сцены ещё
не внедрены; следующий шаг — R2.2.
