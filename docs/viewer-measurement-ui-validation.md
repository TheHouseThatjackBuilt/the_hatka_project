# Приёмка R2.3 — оформление измерений

Дата: 2026-09-15. Этап из [плана редизайна](viewer-redesign-plan.md) завершён.
Основа композиции — [R2.2](viewer-composition-validation.md).

## Что изменилось

MeasurementPanel использует Button, IconButton, Select и StatusBadge из R1.
Заголовок, четыре инструмента и действия остаются на месте, данные прокручиваются
отдельно. Результат представлен названием и таблицей значений; исходный текст
об основаниях размеров доступен через раскрытие «Основания размеров».

На desktop панель справа, на мобильном снизу: высота 300 px с ограничением
40dvh. В коротком горизонтальном окне она справа шириной 240 px. Инструменты
расположены в четыре колонки на мобильном, в две при ширине менее 360 px.
Кнопка закрытия и Escape возвращают фокус на «Размеры».

SVG использует токены темы: акцентные линии с тёмной подложкой, светлый текст
с тёмной обводкой, согласованные контуры и точки. Вычисления, размещение
размеров, picking и геометрия модели не изменены.

При интеграции обнаружен и исправлен дефект Select: после прокрутки поля за
край панели его список оставался над сценой. Теперь он закрывается. Прокрутка
самого списка продолжает работать независимо от панели.

- `npm run typecheck` — успешно.

gzip 170,16 kB. Новые зависимости не добавлялись.

Повторное монтирование проверено на отдельной dev-странице с настоящим App
в StrictMode. Размонтирование при открытом Select удаляет canvas, SVG и portal;
после отложенной очистки R3F roots = 0. После возврата — по одному canvas,
SVG, root и открытому popup. С закреплённым измерением за секунду покоя
не добавилось кадров. Ошибок и предупреждений консоли на dev, диагностической
странице и production не обнаружено.
