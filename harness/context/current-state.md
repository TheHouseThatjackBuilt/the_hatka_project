## Реализовано

- Просмотр квартиры на React Three Fiber и three.js: разрез на 1,05 м, полные
  стены высотой 2,7 м, план сверху. Потолок скрыт во всех режимах просмотрщика.
- Вращение, перемещение и масштабирование камеры, вписывание модели,
  мышь и жесты двумя пальцами. Переключатели видимости мебели и названий.
- Состояния загрузки и ошибки, скачивание GLB, адаптивный интерфейс.
  Подписи скрываются в режиме полных стен; на узком экране в 3D показывается
  сокращённый набор, на плане сверху — все подписи.
- Генератор перенесён с Python на TypeScript с сохранением исходной модели:
  761 деталь, 20 материалов, 9 подписей. Общая оболочка, комнаты и мебель
  разнесены по модулям; каждая сборка создаёт независимые данные.
- Экспорты JSON, GLB, OBJ/MTL генерируются CLI. Проверка их актуальности
  встроена в сборку сайта. Настроен workflow публикации на GitHub Pages.

Описание текущих правок помещений — в [README.md](../../README.md).
Отчёт завершённой миграции —
[typescript-migration-validation.md](../../docs/typescript-migration-validation.md).

## Ограничения и допущения

- Квартира остаётся приблизительной реконструкцией по фотографии планировки.
  Часть размеров выведена из исходных данных; наличие числа в коде не означает
  подтверждённый обмер. Исторические допущения —
  в [reference/README.md](../../reference/README.md).
- Это просмотрщик. Выбор и перетаскивание отдельных предметов, история
  изменений, сохранение пользовательской расстановки и редактор материалов
  пока не реализованы.
- Модель хранит плоский список примитивов в мировых координатах.
  Предметных ID, локальных координат предметов и реестра редактируемой мебели
  пока нет.
- Тест текущего генератора пока привязан к полному эталону миграции и числу
  деталей. Намеренное изменение квартиры требует пересмотра этих проверок
  по [правилам эталонов](../../tests/fixtures/README.md); исторические данные
  для проверки экспортёров сохраняются.
- Автотесты не покрывают полный запуск WebGL, DOM и жесты в браузере.
  Изменения интерфейса и сцены требуют отдельной визуальной проверки.
- `public/preview.png` и `docs/original-validation.json` — исторические
  материалы, не обновляемые генератором.

## Направление следующих работ

Перенос генератора на TypeScript завершён. Решением пользователя 2026-09-09
предметные ID, локальные координаты, отделение исходной расстановки,
переделка генератора под предметы и редактор перемещения отложены в бэклог
без срока. Это отказ от текущей реализации, а не удаление идей навсегда.
Они не являются условием перехода на R3F и не возобновляются автоматически.

Миграция просмотрщика на R3F реализована по согласованной задаче.
Созданы декларативная сцена, ручная OrthographicCamera, существующие controls
и labels, demand rendering, ready/error callbacks и ручное владение общим пулом
ресурсов. Используется отдельный canvas на mount и явный renderer bootstrap,
поскольку ошибки WebGL и `root.configure()` должны попадать в загрузчик.
Плоская модель, генератор, экспорты и поведение интерфейса сохранены. Проверки
и ограничения описаны в [отчёте](../../docs/r3f-viewer-migration-validation.md).
Следующий функциональный этап пока не согласован; отложенный редактор
не запускается автоматически после этой миграции.

## Проверенное состояние

2026-09-09 после перехода на R3F прошли typecheck, 27 тестов и build с
model:check. В браузере проверены режимы, управление, подписи, resize,
повторное монтирование, отказы загрузки и production по пути в подкаталоге.
Мультитач проверен синтетическими PointerEvent, а не физическим устройством.
Общий format:check отмечает 34 прежних файла с CRLF вне задачи; список и
остальные ограничения — в [отчёте](../../docs/r3f-viewer-migration-validation.md).

При ревью harness 2026-09-08 прошли `npm run build` (включая model:check
и TypeScript), все 24 Node-теста и `npm run format:check`. Экспорты актуальны.
Браузерная проверка в этом ревью не проводилась. Это результат того запуска,
а не гарантия для следующих изменений.

Отдельно отчёт приёмки миграции фиксирует проверку сайта в трёх режимах
и выполнение общего генератора и сериализаторов в браузере без Node.js API.
Эти исторические проверки не входят в постоянный автоматический набор.
