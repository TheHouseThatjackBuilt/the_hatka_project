# 3D-модель квартиры

Модель восстановлена по фотографии планировки, предоставленной пользователем. Высота от чистого пола до потолка — **2,700 м**. Размеры модели заданы в метрах.

## Файлы

- `apartment.glb` — основной файл с отдельными объектами, материалами и группами. Подходит для импорта в Blender и другие редакторы с поддержкой glTF 2.0. Сцена по умолчанию без потолка; вторая сцена содержит потолок.
- `apartment.obj` + `apartment.mtl` — запасной формат импорта, оба файла должны лежать рядом. В этой версии потолок исключён для удобства просмотра.
- `model.json` — исходные параметры каждого объекта: положение, размер, материал, категория.
- `build_model.py` — скрипт повторной генерации GLB и OBJ, использует стандартную библиотеку Python 3.
- `viewer.html` — вращаемый просмотр в браузере. Для загрузки библиотеки Three.js требуется интернет; сама геометрия включена в файл.
- `preview.png` — обзор модели.

## Что перенесено

Контур квартиры с выступом входной зоны, стены и перегородки, оконные и дверные проёмы, кухня-гостиная, верхняя правая комната с рабочим столом и диваном, основная спальня, два санузла, гардеробная и правый наружный выступ, интерпретированный как балкон. Основные предметы мебели, кухонные модули, сантехника и хранение расположены по плану. Их отделка выбрана условно: светлая штукатурка, дерево и нейтральный текстиль.

## Допущения и точность

Это объёмная реконструкция по фотографии, а не обмерная или рабочая BIM-модель. На фото есть перспективные и локальные искажения бумаги, а общего размерного контура нет. Подписанные размеры использованы как опорные; неподписанные длины восстановлены по пропорциям. Прямые стены выровнены по ортогональной сетке. Из-за отсутствия всех размерных цепей точность неподписанных участков не установлена.

- Основной внешний прямоугольник: примерно 10,47 × 7,30 м с учётом стен; общая глубина с входным выступом около 8,50 м. Это результат реконструкции, а не размер, написанный на плане.
- Толщина наружных стен принята 240–250 мм; внутренних перегородок — 120–150 мм; отдельных простенков — 240–250 мм по их изображению.
- Высота обычных дверных проёмов принята 2100 мм, балконного — 2200 мм. Ширины дверей без читаемой подписи приблизительные. Открытое положение полотен служит для объяснения проходов.
- Подоконники приняты на отметке 850 мм; верх оконных проёмов — 2350 мм. Импосты и оконные профили схематичны.
- Глубины помещений, не подтверждённые читаемыми размерными цепями, восстановлены по пропорциям. Например, основная спальня принята глубиной 3390 мм от стены со стороны шкафа до южной внутренней грани.
- Высота шкафов принята 2550 мм, столов 780 мм, кухонной столешницы 895 мм. Вертикальные размеры мебели и её внешний вид на исходном плане не заданы.
- Правый внешний прямоугольник трактуется как балкон глубиной около 1000 мм. Его конструкция и ограждение на плане не уточнены; ограждение высотой 1050 мм условное.
- Обозначенные цветы, шторы, бытовая техника, фитостена и места для животных показаны упрощённо.
- Площадь квартиры не рассчитывалась как обмерная величина. Скрытые коммуникации, несущая способность, состав стен, электрика и вентиляция не моделировались.

## Просмотр и импорт

Откройте `viewer.html` в Chrome или Edge. Область модели занимает всю доступную высоту окна и меняется вместе с его размером. Вращение — левая кнопка мыши; перемещение — правая кнопка, нажатое колёсико или Shift + левая кнопка. Кнопка «Перемещать» включает перемещение обычным перетаскиванием, в том числе на телефоне. Колёсико приближает к точке под курсором; два пальца позволяют перемещать и масштабировать модель. «Вписать модель» возвращает всю квартиру в видимую область. Для дополнительного пространства можно включить полноэкранный режим браузера клавишей F11.

Можно переключать разрез, полную высоту стен и вид сверху. Режим разреза скрывает верх стен и высокой мебели на отметке 1050 мм только в просмотре. В GLB стены сохраняют высоту 2700 мм.

В Blender: «Файл → Импорт → glTF 2.0», выбрать `apartment.glb`. Отдельные группы: `FLOOR`, `WALLS`, `WINDOWS`, `DOORS`, `FURNITURE`, `BALCONY`, `CEILING`. Основной файл использует ось Y вверх согласно glTF; Blender конвертирует её при импорте.

Для уточнения геометрии пригодится скан без перспективы либо PDF/DWG с полными размерными цепями и высотами проёмов.
